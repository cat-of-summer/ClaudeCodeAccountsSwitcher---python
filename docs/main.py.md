## Назначение

Единственная точка входа. Определяет режим работы по имени, под которым запущен бинарник, и инициализирует язык интерфейса.

## Режим по имени файла

Один и тот же артефакт работает двумя способами — переключателя между ними нет:

| Запущен как | Режим | Модуль |
|---|---|---|
| `claude` / `claude.exe` | обёртка | `app.wrapper` |
| любое другое имя (`ccas`) | менеджер | `app.cli` |

Установщик кладёт в `~/.claude-switcher/bin` две копии одного файла — `claude` и `ccas`. Флага, выбирающего режим, нет намеренно: shim, оказавшийся в PATH, физически не может быть вызван «не в том» режиме.

Имя берётся из `Path(argv[0]).stem.lower()`. При запуске `python main.py` stem равен `main`, то есть разработчик всегда попадает в режим менеджера.

## Инициализация языка

`_init_language()` вызывается до разбора аргументов, потому что строки справки argparse строятся через `t()` и должны быть уже переведены.

Порядок приоритета:

1. Переменная окружения `CCAS_LANG`
2. Поле `language` в `config.json` (записывается при установке)
3. Автоопределение по системе — см. [ui/i18n.py](ui/i18n.py.md)

Чтение конфига обёрнуто в `try`: до установки файла ещё нет, и это нормальная ситуация, а не ошибка.
