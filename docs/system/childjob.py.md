# childjob.py
<!-- DOCGEN:END -->

## Назначение

Дети, умирающие вместе с нами. Окно транспорта держит несколько процессов claude, а у окна есть крестик: Windows шлёт `CTRL_CLOSE_EVENT` и через несколько секунд убивает транспорт, но запущенные им claude — отдельные процессы, и ничего их не останавливает. Они остались бы в памяти, удерживая слот и каталог кредов, пока кто-нибудь не заметит их в диспетчере задач.

## Как

Windows: job-объект с `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE`, каждый claude добавляется в него `AssignProcessToJobObject`. Что бы ни случилось с транспортом — хоть `taskkill /F` — ядро закрывает handle и убивает детей. Плюс `SetConsoleCtrlHandler` на закрытие окна, выход из системы и выключение: это даёт ~5 секунд, чтобы закрыться по-хорошему (закрыть stdin, дождаться, добить).

POSIX: та же роль у группы процессов, поэтому здесь достаточно запомнить детей и убить их по `SIGHUP`/`SIGTERM`.

`Ctrl+C` и `Ctrl+Break` сюда не относятся: это человек прерывает ход, а не конец процесса.
