# procs.py
<!-- DOCGEN:END -->

## Назначение

Узнать, кто запущен из нашего каталога `bin/`, и закрыть его. Нужно установке: Windows не даёт перезаписать работающий `.exe`, и обновление молча уходило в отложенную замену — новая версия ложилась рядом как `.new`, а работала по-прежнему старая.

## Как

| Функция | Что |
|---|---|
| `running()` | все видимые процессы как `(pid, путь к exe)` |
| `using(каталог, skip=…)` | те из них, чей бинарник лежит в каталоге; свой pid исключён всегда |
| `kill(pid)` | закрыть процесс вместе с детьми; `True`, если после этого его нет |
| `alive(pid)` | жив ли |

Windows: `CreateToolhelp32Snapshot` + `QueryFullProcessImageNameW` через ctypes (хэндлам обязательно проставляются `restype`/`argtypes`, иначе на 64 битах они обрезаются), закрытие — `taskkill /PID … /T /F`, чтобы не осталось детей. POSIX: `/proc/<pid>/exe` и `SIGKILL`. Процесс, к которому нет доступа, просто не попадает в список — это не ошибка.

> [!note]
> Свой собственный файл процесс освободить не может, поэтому `using()` никогда не возвращает текущий pid: для этого случая в установщике есть отложенная замена через `.new`.
