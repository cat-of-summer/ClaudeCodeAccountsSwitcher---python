## Назначение

Правка PATH на Linux. Реестра нет, поэтому каталог shim добавляется из стартовых файлов шелла.

## Блок с маркерами

Каждая правка обёрнута в маркеры:

```sh
# >>> ccas >>>
export PATH="/home/user/.claude-switcher/bin:$PATH"
# <<< ccas <<<
```

Установка, накат и удаление за счёт этого идемпотентны: мы трогаем только текст между своими маркерами и никогда — остальное содержимое rc-файла. Обрыв на полпути (есть начальный маркер, нет конечного) обрабатывается отдельно и не приводит к порче файла.

## Три шелла

| Шелл | Файл | Синтаксис |
|---|---|---|
| bash | `~/.bashrc` | `export PATH=...` |
| zsh | `~/.zshrc` | `export PATH=...` |
| fish | `$XDG_CONFIG_HOME/fish/config.fish` | `fish_add_path -m` |

У fish своя грамматика и своё расположение конфига — пропустить его значило бы для его пользователей молча ничего не сделать. Флаг `-m` перемещает запись в начало, если она уже есть.

## Какие файлы создаются

Правится файл, который **уже существует**, плюс rc текущего шелла из `$SHELL`. Создавать `~/.zshrc` человеку, никогда не запускавшему zsh, — самонадеянно.
