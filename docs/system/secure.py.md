# secure.py

## Назначение

Права доступа «только владелец» для файлов с токенами.

## Почему не шифрование

Креды хранятся открытым текстом — ровно так же, как их хранит сам Claude Code в `~/.claude/.credentials.json`. Файл обязан оставаться читаемым для процесса claude, поэтому зашифровать его на месте нельзя: claude не знает нашего ключа.

Единственное, что реально можно сделать, — закрыть доступ всем, кроме текущего пользователя. Уровень защиты получается тот же, что у штатного файла Claude Code, не хуже и не лучше.

## Как именно

| Платформа | Механизм |
|---|---|
| POSIX | `chmod 700` на каталог, `600` на файл |
| Windows | `icacls <dir> /inheritance:r /grant:r <user>:(OI)(CI)F` |

На Windows `harden_file` — намеренно пустышка: файлы наследуют ACL от урезанного родительского каталога, а запускать `icacls` при каждой записи кредов было бы неоправданно дорого.

## Мягкие отказы

Неудача при выставлении прав никогда не фатальна — она поднимается как `PermissionWarning` и подавляется вызывающей стороной. Вместо падения проблему показывает `ccas doctor`: `is_world_readable` проверяет, не открыт ли файл группе или остальным.

На Windows `is_world_readable` всегда возвращает `False`: биты режима там ничего не значат, а разбор ACL оставлен утилите `icacls`.
