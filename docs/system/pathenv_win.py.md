# pathenv_win.py
<!-- DOCGEN:END -->

## Назначение

Правка PATH на Windows на уровне пользователя. Только `HKCU\Environment` — ни прав администратора, ни машинных настроек.

## Главная ловушка: тип значения

Пользовательский `Path` почти всегда имеет тип `REG_EXPAND_SZ` и часто содержит записи вида `%USERPROFILE%\...`.

Если перезаписать его как `REG_SZ`, эти записи «застынут» в том виде, в каком они разворачиваются сегодня, и PATH пользователя тихо сломается — например, перестанет следовать за переносом профиля.

Поэтому тип читается вместе со значением и возвращается на место неизменным.

Сравнение записей идёт через `os.path.expandvars` только для сопоставления; в реестр всегда пишется исходный текст остальных записей.

## Позиция в списке

`ensure_first` ставит каталог shim **в начало**. Это и есть механизм перехвата: наш `claude.exe` должен находиться раньше настоящего в `~/.local/bin`.

## Оповещение

После записи рассылается `WM_SETTINGCHANGE` с параметром `Environment` через `SendMessageTimeoutW`. Это сообщает уже запущенным оболочкам, что окружение изменилось.

Работает не везде: обычный `cmd.exe` и PowerShell своё окружение не перечитывают. Поэтому установщик всё равно просит открыть новый терминал, а `ccas doctor` считает промах перехвата в текущем терминале предупреждением, а не ошибкой.
