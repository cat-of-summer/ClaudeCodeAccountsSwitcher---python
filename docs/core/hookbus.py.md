# hookbus.py
<!-- DOCGEN:END -->

## Назначение

Шина событий claude для одной запущенной сессии. Поднимает HTTP-слушатель на loopback, формирует файл настроек, в котором все события claude направлены на него хуком типа `http`, и раздаёт полученные события подписчикам.

## Почему HTTP, а не команда

ccas собран в один файл PyInstaller: каждый запуск бинарника — около секунды распаковки. Хук `command` стоял бы перед каждым вызовом инструмента и замедлил бы сессию вдвое. HTTP-хук на 127.0.0.1 отвечает за миллисекунды, процессов не порождает.

## Как подключается

`wrapper.launch()` (и драйвер транспорта) вызывают `open_hook_bus()` → `prepare_args()`: файл `sessions/<pid>.settings.json` записывается и добавляется в командную строку как `--settings`. Если пользователь передал свой `--settings` (файл или JSON), он читается и сливается (`merge_settings`): его ключи сверху, списки хуков объединяются. Нечитаемый `--settings` пользователя не прокидывается — claude принимает один такой флаг; факт попадает в журнал. После выхода claude файл удаляется.

Подкоманды claude (`mcp`, `doctor`…) хуков не порождают, `--bare` и `--safe-mode` их отключают — для таких запусков шина не поднимается (`wrapper.wants_hook_bus`).

## События

`HOOK_EVENTS` перечисляет все события по документации claude (https://code.claude.com/docs/en/hooks). Таймаут ответа: 600 с для `PreToolUse`, `PermissionRequest`, `Elicitation` (ответ может ждать человека в чате), 30 с для остальных, `SessionEnd` — без переопределения (у claude свой бюджет 1.5 с).

## Потребители, по порядку

1. `subscribe(fn)` — подписчики в процессе. `fn(event) -> dict | None`; первый непустой словарь уходит claude как ответ хука.
2. Внешние обработчики из `config.hooks` (`Handler`): `event` — имя, несколько через `|`, или `*`; `matcher` — regex по `tool_name`. `sync: true` — ждём stdout (JSON) и отдаём claude; код выхода 2 превращается в deny с причиной из stderr, как в самом claude. Без `sync` — поток, вывод игнорируется. В stdin — JSON события, в окружении `CCAS_HOOK_EVENT`, `CCAS_SESSION_ID`, `CCAS_SLOT`.
3. Одна строка на событие в `ccas.log` (`HookEvent.summary()`).

Сломанный потребитель не должен подвесить claude: исключения ловятся, ответ — `{}`.

## Артефакты остаются локальными

Режима «артефакт только файлом» у claude нет: `enableArtifact: false` и `CLAUDE_CODE_DISABLE_ARTIFACT` убирают инструмент `Artifact` целиком, а вместе с ним и умение агента собрать страницу, когда она к месту. Поэтому инструмент остаётся, а отклоняется только публикация: `block_artifact_publish` — встроенный подписчик, который на `PreToolUse` для `Artifact` с `action` пустым или `publish` (`is_artifact_publish`) отвечает deny с `ARTIFACT_LOCAL_REASON`: публикация выключена, файл остаётся локальным, назови пользователю путь. Хук срабатывает до проверки разрешений, так что действует и в bypass. Чтение, список, `quickstart` и прочие действия не трогаются.

Подписывает его `wrapper.open_hook_bus`, если в конфиге `artifactPublish` выключен (по умолчанию) — для TUI и для Telegram одинаково. Без шины хуков (`hooks-bus off`) блокировать нечем, и публикация работает как обычно.
