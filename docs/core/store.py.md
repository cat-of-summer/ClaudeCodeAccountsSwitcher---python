## Назначение

Раскладка на диске и всё персистентное состояние: конфигурация установки, таблица слотов, атомарная запись JSON, ротация бекапов.

## Раскладка

```
~/.claude-switcher/
  bin/  claude[.exe]              копия артефакта -> режим обёртки
        ccas[.exe]                копия артефакта -> режим менеджера
  config.json                     версия, путь к claude, режим кредов, язык, автосмена
  accounts.json                   слоты: alias, email, accountUuid, usage, token
  creds/<n>/.credentials.json     сюда указывает CLAUDE_SECURESTORAGE_CONFIG_DIR
  creds/<n>/.refresh.lock         лок обмена refresh-токена (core/oauth.py)
  identity/<n>.json               oauthAccount + userID слота
  sessions/<pid>.json             живые обёртки (core/sessions.py)
  switch-plan.json                на какой слот переезжают сессии (app/autoswitch.py)
  backups/claude.json.<ts>        ротируемые бекапы общего конфига
  logs/ccas.log
```

Всё остальное — проекты, история, настройки, плагины — остаётся общим в `~/.claude` и не трогается никогда.

`CCAS_HOME` переопределяет корень; используется тестами, чтобы не касаться реального домашнего каталога.

## Атомарная запись

`write_json_atomic` пишет во временный файл **в том же каталоге**, делает `fsync`, затем `os.replace`. Это важно не для наших мелких файлов, а для `~/.claude.json`: на рабочей машине он занимает мегабайт и содержит всю историю проектов — порванная запись там невосстановима.

Кодировка — UTF-8 **без BOM**, `ensure_ascii=False`. Это повторяет поведение `CC-WriteJsonNoBom` из исходного PowerShell-профиля: Claude Code не ожидает BOM в своих конфигах.

Флаг `harden=False` нужен для файлов, которые читает сам claude, — им нельзя ужимать права до 0600.

## Бекапы

`backup_file` копирует файл в `backups/` с меткой времени и удаляет всё старше `BACKUP_KEEP` поколений. Вызывается перед каждой правкой общего конфига.

## Модель слота

`Slot.label` формирует человекочитаемое имя: `alias (email)`, если есть оба, иначе то, что есть, иначе локализованное «слот N».

`Accounts.next_free_number` заполняет дырки: если заняты 1 и 3, вернёт 2.

`Slot.token` — бухгалтерия обмена refresh-токена: когда обменивали, когда пробовали, чем кончилось.
По ней держится пятиминутный кулдаун, иначе мёртвый аккаунт стоил бы round-trip на каждом листинге.

## Пустой список — это значение

`defaultArgs` читается через проверку типа, а не через `raw.get(...) or DEFAULT_ARGS`. Прежний
вариант превращал явно пустой список обратно в `["--dangerously-skip-permissions"]`: пользователь,
отказавшийся от флага, получал его назад при следующей же загрузке конфига. Тот же класс ошибки —
`maxSwitches: 0`, «не переключаться никогда», которое `or` читал как «не задано».

## Автосмена в конфиге

`autoSwitch` при загрузке **сливается** с дефолтами, а не берётся как есть: конфиг, написанный
прошлой версией, не содержит ключа, добавленного этой, и чтение такого ключа упало бы в самый
неподходящий момент.

`migrate_config` поднимает `schema` с бекапом. Данных сегодня конвертировать нечего — всё читается
через дефолт, — но версия на диске нужна, чтобы будущее ломающее изменение знало, что видит.
