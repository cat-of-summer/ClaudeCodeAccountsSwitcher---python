# version.py

## Назначение

Единственный источник правды о версии.

| Константа | Смысл |
|---|---|
| `__version__` | версия приложения; попадает в `config.json` при установке |
| `SCHEMA_VERSION` | версия раскладки `config.json` / `accounts.json` |

## Как это используется

`ccas doctor` сравнивает `__version__` запущенного бинарника с полем `version` из установленного конфига. Расхождение означает, что рядом лежит более свежий бинарник и его стоит накатить.

`SCHEMA_VERSION` поднимается **только** когда меняется формат файлов состояния и требуется миграция. Обычный релиз его не трогает.

Тег релиза в git и `__version__` не связаны автоматически — при выпуске новой версии значение здесь нужно поднять руками.
