# menu.py
<!-- DOCGEN:END -->

## Назначение

Интерактивный выбор аккаунта, который показывается при голом `claude` в терминале.

## Примитивы экрана

Чтение клавиш, цвета и перерисовка живут в [`ui/screen.py`](screen.py.md) — там же объяснено, почему
без curses и prompt_toolkit. Здесь остались только строки меню и его цикл.

## Клавиши

| Клавиша | Действие |
|---|---|
| стрелки | выбор |
| Enter | запустить выбранный слот |
| цифра | перейти к слоту с этим номером |
| `r` | опросить лимиты по всем слотам |
| `u` | опросить лимиты только по выбранному |
| `s` | экран настроек |
| `a` | добавить аккаунт |
| `q`, Escape | выход без запуска |

`u` — не `Shift+R`: `read_key` приводит символ к нижнему регистру, и различить их нельзя. Смысл
отдельной клавиши в цене: `r` блокирует интерфейс на таймаут, умноженный на число слотов, `u` — на
один запрос.

«Добавить аккаунт» возвращает следующий свободный номер. Обёртка запустит его без сохранённых кредов, и claude сам уйдёт в свой сценарий входа.
