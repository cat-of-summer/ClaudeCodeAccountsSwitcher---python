# menu.py
<!-- DOCGEN:END -->

## Назначение

Интерактивный выбор аккаунта, который показывается при голом `claude` в терминале.

## Почему только стандартная библиотека

Ни curses, ни prompt_toolkit. Обёртка собирается в один onefile-бинарник, и каждая зависимость здесь — это вес, оплачиваемый при **каждом** запуске, включая куда более частый неинтерактивный путь.

Чтение клавиш: `msvcrt.getwch()` на Windows, `termios` + `tty` на POSIX. Перерисовка — ANSI-последовательностями.

## Escape против стрелки

На POSIX стрелка приходит как `\x1b[A`, а одиночный Escape — как `\x1b` и больше ничего. Различаются коротким `select` с таймаутом 50 мс: если продолжения нет, это был Escape.

## Windows и ANSI

`enable_ansi()` включает `ENABLE_VIRTUAL_TERMINAL_PROCESSING` в консоли. Без этого на старых сборках Windows вместо оформления печатались бы сырые управляющие последовательности.

## Клавиши

| Клавиша | Действие |
|---|---|
| стрелки | выбор |
| Enter | запустить выбранный слот |
| цифра | перейти к слоту с этим номером |
| `r` | опросить лимиты по сети |
| `a` | добавить аккаунт |
| `q`, Escape | выход без запуска |

«Добавить аккаунт» возвращает следующий свободный номер. Обёртка запустит его без сохранённых кредов, и claude сам уйдёт в свой сценарий входа.
