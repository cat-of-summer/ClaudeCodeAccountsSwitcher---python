# usage.py
<!-- DOCGEN:END -->

## Назначение

Информация о лимитах для меню и команды `ccas usage`.

## Два источника

Ни одного из них по отдельности не хватает:

* **Снимок, который claude сам оставляет** в `cachedUsageUtilization` после сессии. Бесплатный и мгновенный, но описывает только тот аккаунт, что работал последним, — а при выборе аккаунта интересны как раз остальные.
* **Живой `GET https://api.anthropic.com/api/oauth/usage`** токеном конкретного слота. Точен для всех, но стоит round-trip.

Меню показывает снимок сразу и опрашивает сеть только по явной команде, поэтому запуск claude никогда не ждёт сети.

## Запрос

```
GET https://api.anthropic.com/api/oauth/usage
Authorization: Bearer <accessToken слота>
anthropic-beta: oauth-2025-04-20
```

Слоты опрашиваются параллельно, таймаут 5 секунд на каждый. Ошибка или протухший токен не роняют меню — такой слот просто остаётся с прежними цифрами.

## Отображение

`format_usage` собирает строку вида `5ч 46% ↻ 05.08 18:50 · 7д 96% ↻ 12.08 09:00 · (2 ч назад)`. Возраст снимка дописывается, только если он не «сейчас» — иначе это шум.

Момент сброса идёт при своём окне, а не общим хвостом: недельное окно откатывается через несколько суток, и одна метка в конце строки не сказала бы, к какому из двух окон она относится. Окно без `utilization` не выводится вовсе — сам по себе сброс строку не порождает.

Время сброса приходит в ISO 8601 с зоной (`2026-07-24T13:50:00.360619+00:00`) и переводится в локальную зону пользователя. Дата показывается всегда: без неё «сброс 09:00» у недельного окна бесполезно. Год не выводится — сброс всегда в пределах ближайших семи дней.

Раскладка задаётся каталогами, а не кодом: `usage.reset_at` держит метку-глиф (`↻ {time}`), `usage.reset_format` — строку формата для `strftime` (`%d.%m %H:%M` в ru, `%m-%d %H:%M` в en). Если ключа формата в каталоге нет, `format_reset` откатывается на `DEFAULT_RESET_FORMAT`: `i18n.t()` при промахе возвращает само имя ключа, и без этой проверки оно уехало бы в вывод литералом.
