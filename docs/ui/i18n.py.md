# i18n.py
<!-- DOCGEN:END -->

## Назначение

Мультиязычность. Весь текст, который видит пользователь, идёт через `t()`; в коде не должно оставаться ни одной зашитой фразы.

## Каталоги

Плоские файлы `lang/<код>.json` с точечными ключами:

```json
{ "install.header_installed": "Установлено: ccas {version}" }
```

Подстановка — обычный `str.format`. Если плейсхолдер не сойдётся, `t()` вернёт шаблон как есть, а не упадёт: сломанный перевод не должен ронять приложение.

Поиск каталогов: `sys._MEIPASS/lang` в собранном бинарнике (PyInstaller кладёт их туда как data), иначе `lang/` рядом с исходниками.

## Определение языка

Порядок приоритета:

1. `CCAS_LANG` — переменная окружения, перебивает всё
2. Значение, переданное явно (поле `language` из `config.json`)
3. Системный язык

Системный определяется так:

* сначала `LANGUAGE`, `LC_ALL`, `LC_MESSAGES`, `LANG` — это покрывает Linux;
* на Windows эти переменные обычно не заданы, поэтому спрашиваем `GetUserDefaultUILanguage()` и смотрим на primary language ID (`0x19` — русский);
* иначе `en`.

Устаревший `locale.getdefaultlocale()` сознательно не используется.

`normalise` приводит `ru_RU.UTF-8`, `en-US` и подобное к двухбуквенному коду и отбрасывает неподдерживаемые языки.

## Фолбэк

Если ключа нет в текущем каталоге, берётся английский. Если нет и там — возвращается сам ключ. Отсутствующий перевод виден в интерфейсе, но ничего не ломает.

## Проверка каталогов

Тесты сверяют, что у всех языков **совпадают наборы ключей и наборы плейсхолдеров**. Забытая или лишняя строка в переводе валит тесты, а не всплывает у пользователя.
