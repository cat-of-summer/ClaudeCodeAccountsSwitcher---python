# prompter.py
<!-- DOCGEN:END -->

## Назначение

Превращает `can_use_tool` в то, на что можно ответить из чата, и отвечает claude, когда ответ собран.

## Два вида запросов

- `AskUserQuestion`: вопросы задаются по одному, каждый — сообщение с кнопками по вариантам, «Свой ответ» (следующее текстовое сообщение) и, для `multiSelect`, переключатели с «Готово». Когда отвечен последний — `allow` с `updatedInput = tool_input + answers`.
- Разрешение на инструмент: «Разрешить / Всегда (сессия) / Запретить». «Всегда» возвращает `permission_suggestions` claude как `updatedPermissions`. Тело — `describe_input`: команда, путь, URL — то одно, что человек хочет увидеть перед «да».

## Кнопки и консоль

`callback_data` — `a:<номер запроса>:<номер вопроса>:<вариант|t|d|y|s|n>`; сессия добавляет спереди свою метку (`tag`), чтобы демон отдал нажатие нужной сессии. Нажатие на устаревший вопрос отвечается подсказкой, а не ошибкой. Локальная консоль отвечает тем же: цифра выбирает кнопку, `y`/`n` — разрешение, свободный текст — «свой ответ».

## Таймаут

`tick()` вызывается сессией раз в секунду: запрос без ответа дольше `telegram-prompt-timeout` отклоняется с причиной, чтобы claude не висел; 0 — ждать бесконечно.
