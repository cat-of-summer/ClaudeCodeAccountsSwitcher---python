# prompter.py
<!-- DOCGEN:END -->

## Назначение

Превращает `can_use_tool` и `elicitation` в то, на что можно ответить из чата, и отвечает claude, когда ответ собран.

## Четыре вида запросов

- `AskUserQuestion`: вопросы задаются по одному, каждый — сообщение с кнопками по вариантам, «Свой ответ» (следующее текстовое сообщение) и, для `multiSelect`, переключатели с «Готово». Когда отвечен последний — `allow` с `updatedInput = tool_input + answers`.
- `ExitPlanMode`: план и кнопки «Выполнять» / «Выполнять, спрашивая» / «Доработать». Согласие — `allow` плюс `updatedPermissions: [{"type": "setMode", "mode": …, "destination": "session"}]`: в CLI выход из plan-режима и есть одобрение этого инструмента, и режим меняется тем же ответом. Отказ — `deny` с причиной, после которого агент переделывает план.
- Разрешение на инструмент: «Разрешить / Всегда (сессия) / Запретить». «Всегда» возвращает `permission_suggestions` claude как `updatedPermissions`. Тело — `describe_input`: команда, путь, URL — то одно, что человек хочет увидеть перед «да».

- Запрос MCP-сервера (`elicitation`): заголовок из `title`/`display_name` или имени сервера, текст `message`, дальше поля `requested_schema` по одному. `boolean` — «Да» / «Нет», `enum` — кнопка на значение, остальное — свободный текст следующим сообщением (`number`/`integer` проверяются). Когда поля кончились — `{"action": "accept", "content": …}`; «Отказать» — `decline`, «Отмена» и таймаут — `cancel`. При `mode: "url"` полей нет: показывается ссылка и кнопка «Готово».

## Кнопки и консоль

`callback_data` — `a:<номер запроса>:<номер вопроса>:<вариант|t|d|y|s|n>`; сессия добавляет спереди свою метку (`tag`), чтобы демон отдал нажатие нужной сессии. Нажатие на устаревший вопрос отвечается подсказкой, а не ошибкой. Локальная консоль отвечает тем же: цифра выбирает кнопку, `y`/`n` — разрешение, свободный текст — «свой ответ».

## Таймаут

`tick()` вызывается сессией раз в секунду: запрос без ответа дольше `telegram-prompt-timeout` отклоняется с причиной, чтобы claude не висел (запрос MCP-сервера — `cancel`, у него нет `deny`); 0 — ждать бесконечно.
