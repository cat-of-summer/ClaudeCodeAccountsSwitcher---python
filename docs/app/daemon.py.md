# daemon.py
<!-- DOCGEN:END -->

## Назначение

Процесс, который опрашивает бота и раздаёт строки чата сессиям. Один на токен — Telegram не даст двух, лок это отражает локально. Всё остальное следует из этого факта.

## Жизненный цикл

`ccas daemon run [--hidden]`: проверка конфига, лок токена, локальный HTTP на 127.0.0.1 (порт в `daemon.json` и в локе), поллер, цикл с обновлением лока и чисткой маршрутов, обработка SIGINT/SIGTERM. `--hidden` прячет окно консоли на Windows (`ShowWindow(GetConsoleWindow(), 0)`) — так демона запускает автозапуск. `ensure_running` — ленивый старт из любого `ccas`/`claude`, если `telegram-daemon` включён, а демон не жив; при отсутствии frozen-бинарника запускается текущий интерпретатор с `main.py`.

## Маршруты

Сессия регистрирует `Route(pid, tag, chat, thread, alias, cwd, slot)` и опрашивает `/poll?pid=…` long-poll-запросами. Маршрут без опроса 90 с или с мёртвым pid удаляется. Апдейт направляется так: кнопка — по метке (`tag`) в `callback_data`, `d:` — кнопки демона; текст — `routing.address`: алиас → его сессия; `/claude` → запуск; команда демона; иначе безымянная сессия чата; иначе тишина (подсказка — только на слэш-команду или при заданном префиксе, чтобы не отвечать на чужой разговор в группе).

Чужие чаты: демон принимает сообщения из чата по умолчанию и из чатов, где живут маршруты (сессии с `--tg-chat`).

## /claude

`/claude [слот] [-n имя] [-C каталог] [аргументы]` — те же аргументы, что у `claude` в терминале. Подкоманды и `-p`/`--version`/`--help` выполняются разово с захватом вывода. Иначе: имя валидируется, профиль (если есть) должен быть привязан к этому чату, второе безымянное или одноимённое в чате отклоняется, каталог выбирается по цепочке `-C` → профиль → каталог чата → `telegram-workdir` → домашний (с учётом `roots`), слот — из аргументов или профиля, аргументы профиля идут перед аргументами из чата. Потом `open_window`: Windows — `CREATE_NEW_CONSOLE` (или без окна при `telegram-console off`), Linux — найденный эмулятор терминала, macOS — Terminal через osascript. В окружении спавна `CCAS_TELEGRAM_FEED=1`, `CCAS_TELEGRAM_TAG`, `CCAS_TELEGRAM_DAEMON_PORT`.

## Каталоги

Каталог чата хранится в `telegram/chats.json` по ключу `chat:thread`. `/projects` берёт `claudecfg.known_projects()` — реальные пути из `~/.claude.json: projects`, существующие, без дублей, новые первыми — и показывает их кнопками постранично.
