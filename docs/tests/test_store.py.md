Хранилище состояния — 10 тестов.

`TestAccountsStore` — round-trip слотов и конфига через диск, поиск по алиасу без учёта регистра и по префиксу email, заполнение дырок в нумерации (`next_free_number`), сброс активного слота при его удалении.

`TestAtomicWrite` — после записи не остаётся временных хвостов, кириллица не экранируется в `\uXXXX`, BOM не пишется, но при чтении переносится, ротация бекапов держит заданный предел.

BOM тут не придирка: Claude Code не ожидает его в своих конфигах, а Windows-инструменты добавляют охотно.
