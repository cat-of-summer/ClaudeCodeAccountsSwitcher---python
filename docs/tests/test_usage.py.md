Отображение лимитов — 6 тестов.

Проверяется разбор `resets_at` в формате ISO 8601 со смещением (`2026-07-24T13:50:00.360619+00:00`) и вывод процентов пятичасового окна.

Остальное — про устойчивость к неполным данным: битый блок `five_hour`, отсутствующий процент, пустой снимок. Ни один из этих случаев не должен ронять меню — данные приходят из чужого кеша и из сети, и рассчитывать на их форму нельзя.

Подписи состояний токена проверяются на непустоту, кроме `ok`: у здорового токена подписи быть не должно.
