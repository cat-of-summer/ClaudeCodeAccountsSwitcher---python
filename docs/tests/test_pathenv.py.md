# test_pathenv.py
<!-- DOCGEN:END -->

Правка PATH на POSIX — 6 тестов. На Windows пропускаются: там PATH живёт в реестре.

Проверяется, что существующий rc-файл дополняется без потери содержимого, что повторный запуск идемпотентен (маркер ровно один), что `remove` возвращает файл в исходный вид и что fish получает свой синтаксис `fish_add_path`, а не `export PATH`.

Ключевой тест — `test_bare_environment_falls_back_to_profile`. Он закрывает найденный дефект: в окружении без единого rc-файла и без `$SHELL` (Docker, CI, свежий сервер) установка молча не прописывала PATH вообще. Теперь в таком случае создаётся `~/.profile`, и `uninstall` его тоже подчищает.
