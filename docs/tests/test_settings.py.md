# test_settings.py

## Что проверяет

Реестр настроек, разбор значений, схему конфига и команду `ccas config`.

## Два теста, поймавших настоящие дефекты

`test_other_default_args_are_preserved` — `skip-permissions` это вид над списком `defaultArgs`, и
щелчок в меню не должен уносить флаг, дописанный туда руками.

`test_a_config_missing_the_block_gets_the_defaults` вместе с `test_round_trip` закрывают то, из-за
чего пользователь получал `--dangerously-skip-permissions` обратно после явного отказа: пустой
список читался как «ключа нет» и подменялся дефолтом.

## Покрытие каталогов

`test_every_setting_is_labelled_in_every_language` проверяет, что для каждой записи реестра есть
`config.label_*` и `config.help_*` в обоих языках. `i18n.t()` при промахе возвращает само имя ключа,
поэтому забытая строка иначе уехала бы в интерфейс литералом.

Локализованные ответы («да»/«нет») проверяются через `os.environ["CCAS_LANG"]`, а не только через
`set_language`: переменная окружения имеет приоритет, а базовая фикстура пиннит её в `en`.
