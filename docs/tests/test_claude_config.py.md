# test_claude_config.py
<!-- DOCGEN:END -->

Поиск и правка конфигов Claude Code — 8 тестов.

`TestConfigTargets` фиксирует приоритет путей: `<configDir>/.config.json` важнее `~/.claude.json`. Именно этого не знал исходный PowerShell-профиль, из-за чего очередная миграция Claude Code сломала бы его молча. Отдельно проверяется, что инертный `~/.claude/.claude.json` тоже попадает в список целей.

`TestIdentityPatching` проверяет запись во все существующие цели сразу, сохранность посторонних ключей (мегабайт истории проектов терять нельзя), отсутствие BOM и обнуление `oauthAccount` при входе в пустой слот.

Отдельный тест — повторный патч теми же значениями обязан не делать ничего: без этого каждый запуск того же слота вхолостую перезаписывал бы мегабайтный файл.
