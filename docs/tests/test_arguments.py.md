# test_arguments.py
<!-- DOCGEN:END -->

Разбор аргументов обёртки — 13 тестов.

`TestArgumentParsing` проверяет таблицу выбора слота: `2` → номер, `@work` → алиас, `--` → снять и не резолвить, `mcp list` → подкоманда проходит нетронутой, пустой список → активный слот.

Два случая здесь ключевые. `claude work` обязан остаться промптом: если бы алиасы работали без префикса `@`, однословный промпт был бы съеден. `claude -- 2` — аварийный выход для промпта из одних цифр.

`TestDefaultArgs` проверяет подмешивание `default_args`: флаг не дублируется, `--allow-dangerously-skip-permissions` считается тем же флагом, а подкомандам ничего не добавляется.

`TestMenuGating` — меню не всплывает при наличии аргументов или явно выбранном слоте.
