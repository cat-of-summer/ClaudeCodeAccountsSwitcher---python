# test_credentials.py
<!-- DOCGEN:END -->

Состояние токенов — 6 тестов.

Проверяются все четыре значения `token_state` на фиксированном «сейчас», без зависимости от системных часов:

| Состояние | Условие |
|---|---|
| `ok` | оба срока в будущем |
| `expired` | access истёк, refresh жив — claude обновит сам |
| `stale` | истёк и refresh — нужен повторный вход |
| `missing` | файла кредов нет |

Отдельно — извлечение access-токена для запроса лимитов и то, что отсутствующий файл даёт `None`, а не исключение.
