# test_i18n.py
<!-- DOCGEN:END -->

Мультиязычность — 12 тестов.

`TestCatalogs` — главная защита от забытого перевода: у всех языков должны совпадать **наборы ключей** и **наборы плейсхолдеров** каждой строки. Добавил ключ только в один файл — тесты падают, а не пользователь видит английский посреди русского интерфейса. Отдельно проверяется, что списки ответов «да/нет» разбираются в каждом языке.

`TestLookup` — отсутствующий ключ возвращает сам себя, подстановка работает, русский каталог действительно подхватывается.

`TestLanguageDetection` — `CCAS_LANG` перебивает явно переданный язык, `ru_RU.UTF-8` и `en-US` приводятся к двухбуквенному коду, неподдерживаемый язык отбрасывается, `LANG` учитывается, а при пустом окружении берётся английский.
